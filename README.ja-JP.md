## Prism について

Markdown は書きやすい一方で、仕上がりは下書きのままに見えることがあります。Prism が大切にしているのは、その先の体験です。ページの見え方、プレビュー、ファイル同士の関係、そしてエディタの外へ出すときの読みやすさまで、ひと続きの文書として扱います。

Prism 1.0.0 が重視していること:

- **文書らしい執筆画面**: メモ、長文、技術文書に向いた編集、分割、プレビュー。
- **個性のあるテーマ**: MiaoYan、Inkstone、Slate、Mono、Nocturne Dark が、文字、表、コード、引用、プレビュー全体を調整します。
- **知識の構造化**: ローカル Markdown ワークスペースで、リンク、バックリンク、グラフを扱えます。
- **3 言語 UI**: 中文、English、日本語を製品体験の一部として用意しています。
- **プレビューを尊重した書き出し**: HTML、PDF、PNG、DOCX と、壊れたリソースや描画リスクを見つける診断。

## 機能

### 執筆

- ローカル Markdown / テキストファイル編集
- 編集、分割、プレビューの表示モード
- 自動保存と未保存状態の追跡
- 検索、置換、選択、キーボード操作
- ファイルツリー、アウトライン、コンテキストメニュー、ステータスバー

### プレビュー

- GitHub Flavored Markdown
- コードハイライト
- 表、タスクリスト、引用、リンク、マーク、区切り線
- KaTeX 数式
- Mermaid 図表
- PlantUML 図表
- Markmap マインドマップ

### 知識構造

- Wiki 形式リンク
- 現在のリンクとバックリンク
- 文書プロパティ
- ローカル Markdown ワークスペースの関係グラフ

### 書き出し

- HTML
- PDF
- PNG
- Word `.docx`
- 画像不足、壊れたリンク、描画失敗、書き出しリスクの診断

## テーマ

Prism のテーマは単なる色替えではありません。各テーマが、フォント、背景、コードブロック、表、引用、プレビュー全体の関係を持っています。

- **MiaoYan**: 長文執筆と仕上がりプレビュー向け
- **Inkstone**: 紙とインクに近い編集感
- **Slate**: 構造化された技術文書向け
- **Mono**: 白黒の草稿や実験ノート向け
- **Nocturne Dark**: 本格的なダーク執筆画面

## 既知の制限

- 1.0.0 には自動更新配信は含まれていません。このリリースでは updater signing private key が利用できなかったためです。
- Windows と Linux は、まだ 1.0.0 の正式公開プラットフォームではありません。
- 完全オフラインでの描画検証、HiDPI マトリクス、長時間のメモリ圧力テストは、1.0 以降の強化項目です。

## 開発

### 必要環境

- Node.js 18+
- Rust 1.77+
- 利用するプラットフォームに対応した Tauri 2 の前提環境

### ローカルで起動

```bash
git clone https://github.com/AlexPlum405/Prism.git
cd Prism
npm install
npm run tauri:dev
```

### ビルド

```bash
npm run build
npm run tauri:build
```

生成物は次の場所に出力されます。

```text
src-tauri/target/release/bundle/
```

### テスト

```bash
npm test
npm run build
```
