基于你选的 2 号方案继续收敛：左上角保留编辑 / 分栏 / 预览，文件名贴近视图切换显示且去掉 .md 后缀；不显示 P 图标。右上角保留 Windows 用户熟悉的最小化 / 最大化 / 关闭。

左上角视图切换 无 P 图标 文件名无后缀 右上角窗口控制

方案 2 收敛版：纯视图切换标题栏

左侧收敛成“视图切换 + 无后缀文件名”的轻量信息组。中间留出大面积拖拽区域，右侧只承担 Windows 窗口控制。

干净度高 无品牌噪音 窗口习惯保留 发现性中等
proposal
优点 文档名和视图切换形成同一组左侧信息，右上角不再和视图切换冲突，Windows 窗口控制仍符合习惯。
代价 左侧信息密度比居中方案稍高；长文件名需要截断，不能挤压中间拖拽区域。
实现建议 Windows 将 `ViewModeSwitch` 与无后缀文件名作为左侧 title group；macOS 维持当前右上角方案，不必跨平台强行一致。
设计判断：这是目前最接近你要求的 Windows 方案：右上角完全交给系统窗口控制，左上角做 Prism 的视图模式切换，并让文件名贴近视图切换形成同一组信息；没有 P 图标，文件名不显示 .md。落地时需要确保中间留白区域仍可拖拽，避免左侧按钮影响窗口移动。
