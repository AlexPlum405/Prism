Tweaks 变体控制台

实时切换和配置不同的 UI/UX 优化方案细节

1. 暗色模式测试
模拟 Prism 处于深色/夜间写作状态的视觉反差
2. 未保存状态表达 (优化点1)
变体 A 使用慢速灰蓝呼吸圆环；变体 B 使用轻量字形状态提示
呼吸周期: 6s
3. 状态栏防余光闪烁延时 (优化点2)
防止鼠标无意划过底栏时触发频繁闪烁。建议设置为 150ms。
防闪烁延时: 150ms
4. Toggle 折叠块交互 (优化点3)
动态变体使用 60fps 平滑 Grid 折叠；静态变体体现原研哉留白 Placeholder 艺术
5. 文档图谱视觉流派 (优化点5)
切换 Pentagram 骨架印刷派与传统大球粒子派
💡 画书设计专家评审 (Critique)
「减少无关装饰以体现绝对的内容安全，增加在微小处的 120% 细节质感，这就是反 AI Slop 的核心。使用 150ms 延时保护创作者的视线不受余光闪烁干扰，以及使用纯 CSS 的 60fps 动态 Grid 渲染，这些看似不起眼的‘技术性品位’是成就一款伟大写作器的基石。」
