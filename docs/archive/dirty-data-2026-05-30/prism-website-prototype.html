特性

少而准的能力。

不是功能清单,是写作时实际会用到的几件事。

中文长文排版

对照妙言风格,行距、字号、首行缩进、引用都按中文阅读习惯调过。预览即出版样。

可靠的自动保存

本地 .md 文件就在你能看到的地方。崩溃恢复、增量保存、零云端依赖。

单文档单窗口

不做标签页、不做侧栏。一个窗口对应一篇内容,把注意力还给当前这一段话。

五套内容主题

Newsprint / Night / Github / Pixyll / Whitey,每套都为长文阅读各调过一遍。

KaTeX & Mermaid

内置数学公式与图表渲染,写技术稿不用切到第二个工具。

稳定的导出

HTML、PDF、DOCX、PNG。同一份 .md,在哪里读都不丢样式。

工作流

三步,一篇文章。

01 / 起笔

打开窗口,直接写。

没有项目设置、没有同步配置。新建一个 .md 文件就开始,Prism 会替你记得保存这件事。

02 / 排版

对照预览微调。

左编辑、右预览,或全屏专注。引用、代码块、图、公式,都按你写下的样子落位。

03 / 输出

一次导出,处处可读。

导出 PDF 用于打印、HTML 用于发博客、DOCX 用于交稿。同一份内容,样式可控。
