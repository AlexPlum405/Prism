# Prism 排版回归样张

这是一份用于默认预览排版和暗色模式截图回归的 Markdown fixture。它覆盖标题层级、中文长段落、列表、表格、引用、代码块、Callout、Toggle、KaTeX 和 Mermaid。内容不追求业务含义，只用于观察阅读行宽、段距、对比度和复杂块的密度。

## 中文长段落与行宽

Prism 的默认预览应该服务长时间写作和审阅：正文不能在宽屏上无限拉长，也不能因为列宽过窄而像移动端。中文段落需要稳定的行高、可预测的段距和克制的标题层级。这里故意放入较长句子，观察 1200、1440 和 1920 像素宽度下的可读行长是否保持一致，并检查英文 inline words such as Markdown, WebView, Export fidelity 与中文混排时是否仍然自然。

第二段继续模拟真实产品文档：用户在编辑论文、公众号长文、PRD 或技术方案时，会在一个文档里混合叙述、列表、表格、代码、公式和图。预览模式不是营销页面，它应该像可靠的桌面写作器，保持内容安静、边界清楚、信息密度适中。

## 表格、代码与公式

| 项目 | 用户影响 | 验收方式 | 风险 |
|---|---|---|---|
| 正文行宽 | 宽屏阅读不发散 | 1200/1440/1920 截图 | 中 |
| 表格 | 多列信息可扫描 | 不挤压、必要时横向滚动 | 中 |
| 代码块 | 长行不破坏布局 | 等宽字体、适中行高 | 中 |
| 暗色模式 | 长时间阅读不刺眼 | 对比度和块边界可见 | 中 |

```ts
export function describePreviewTypography(width: number) {
  const readableMeasure = width <= 1440 ? 'compact' : 'bounded';
  return `Prism keeps preview measure ${readableMeasure} while preserving table and code affordances.`;
}
```

## 深色模式观察点

暗色主题下正文、引用、表格边框、代码背景、Callout 和 Toggle 不应该糊在一起。正文颜色需要比次级文字更清楚，代码块和表格边界需要可见，但不能像开发工具一样高对比。
