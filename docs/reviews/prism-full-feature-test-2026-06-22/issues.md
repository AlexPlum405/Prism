本文件只记录本轮真实执行中发现的失败项、待确认项和覆盖阻塞。Windows/Linux 未执行项不以推测结果代替。

## ISSUE-001 选区右键菜单没有进入可复制/可链接状态

- 优先级：P0
- 关联用例：TC-P0-010
- 截图引用：screenshots/01-shell/10-selection-context-menu.png
- 用户影响：重度写作者依赖右键复制、加链接、格式化选区。选中后仍禁用复制会破坏基础编辑信任。
- 复现步骤：
  1. 打开 04-linked-note.md
  2. 切换编辑模式
  3. 拖拽选中标题文字
  4. 在选区上右键
- 实际结果：右键菜单显示剪切/复制禁用，且未出现链接动作。
- 预期结果：选区右键菜单应启用复制，并提供常用格式和链接动作。
- 建议修复方向：检查编辑器 selection 状态到上下文菜单的同步；右键前保留 selection；补齐链接入口或明确放入格式子菜单。
- 验收标准：在标题、段落、代码内分别选中文字后右键，复制启用；链接/加粗/斜体动作可用并能正确作用于选区。

## ISSUE-002 表格复制格式缺少 CSV/TSV

- 优先级：P0
- 关联用例：TC-P0-062
- 截图引用：screenshots/06-table/05-table-copy-formats.png
- 用户影响：表格内容迁移到数据表、SQL 工具、Excel/Numbers 时 CSV/TSV 是高频桥接格式，缺失会降低表格功能实用性。
- 复现步骤：
  1. 打开 06-table-heavy.md
  2. 选中表格
  3. 打开表格右键或更多菜单
  4. 展开复制格式
- 实际结果：复制格式菜单只有纯文本、Markdown、HTML。
- 预期结果：复制格式菜单包含 Markdown、HTML、CSV、TSV。
- 建议修复方向：在表格 selection 序列化层增加 CSV/TSV serializer，并在菜单启用对应命令；覆盖转义、空单元格和对齐列。
- 验收标准：同一张表复制为 CSV/TSV 后粘贴到文本编辑器，分隔符、换行和表头正确；菜单截图包含四种格式。

## ISSUE-003 多类浮层/菜单对 Esc 关闭反馈不一致

- 优先级：P1
- 关联用例：TC-P0-019 / TC-P0-020 / TC-P0-008
- 截图引用：screenshots/02-file/07-file-tree-context-menu.png
- 用户影响：键盘用户和高频写作者会用 Esc 退出上下文菜单、全文搜索和工作区菜单；失效会打断连续操作。
- 复现步骤：
  1. 打开文件树右键菜单或工作区菜单
  2. 按 Esc
  3. 观察菜单是否关闭
  4. 打开全文搜索并按 Esc
- 实际结果：多次执行中 Esc 未关闭菜单/浮层，需要点击空白区域关闭。
- 预期结果：所有临时浮层应支持 Esc 关闭，焦点回到触发前区域。
- 建议修复方向：统一 overlay/menu 的 Escape keydown 处理；确认 Tauri WebView 和自绘菜单事件没有被输入框吞掉。
- 验收标准：文件右键、工作区右键、快速打开、全文搜索、查找/替换浮层均可一次 Esc 关闭。
