# Prism 竞品功能与体验差距矩阵（2026-07-26）

> 来源计划：`docs/plans/prism-quality-audit-upgrade-plan-2026-07-26.md` 阶段一渠道 2。
> 竞品版本：Typora 1.14.6、MiaoYan V4.1.0（2026-07-18）、iA Writer 8.0.5（2026-07-17）、Obsidian（仅链接四项）。
> Prism 侧状态：逐项对照代码确认（分支 `codex/prism-full-optimization`，含未提交改动），非凭印象。

## 0. 核心结论（先看这段）

**Prism 的功能覆盖已经超过妙言、逼近 Typora，短板不在功能数量，而在打磨细节、惯例契合与性能。**

- 24 项能力盘点：18 项已实现，4 项部分实现，2 项未实现。
- Prism 独有或领先的能力有 6 组（见 §3），其中"导出诊断 + 后台导出任务 + 四格式内置不依赖 Pandoc"是三家竞品都没有的。
- 真正扎手的差距集中在三类：**惯例冲突**（快速打开快捷键）、**桌面基本功缺失**（拖放打开、文件树拖放移动、应用内更新）、**监听机制弱**（15 秒轮询而非文件系统 watcher）。
- 竞品高票诉求中有多项 Prism 已经做到（wikilink 103👍、CLI/图表/演示、批量能力），说明产品方向判断是对的，不需要转向。

评级说明：`✅有` / `⚠️有但体验差或不完整` / `❌无` / `🟢领先（Prism 更好）` / `⛔超出定位（不做）`

### 2.3 第三梯队 —— 低频或差异化机会

- 图片批量整理（移动全部图片 / 下载远程图到本地）：Typora 有，中低频。
- 字数统计补句数与预计阅读时间：低成本对齐。
- 专注模式句子级粒度（iA Writer 有）。
- **差异化机会（四家皆无）**：写作目标/字数目标、批量导出、导出后自定义命令。
- ⛔ 不做（超出定位，即使竞品高票）：插件系统（Typora 251👍 第一高票）、移动端、演示/PPT 模式、Vim 键位（四家皆无，延后）、学术引用文献全套。

## 3. Prism 已领先的能力（发布叙事应主打）

1. **导出诊断 + 后台导出任务** —— 四家竞品全部没有。对应 CONTEXT.md"导出可信、问题可诊断"的差异主张。
2. **四格式内置导出（含 DOCX）不依赖 Pandoc** —— Typora 的 docx 要装 Pandoc，妙言没有 docx。
3. **PlantUML + Markmap + Mermaid 全覆盖** —— PlantUML 是 Typora 第 6 高票未满足诉求（126👍）。
4. **链接诊断 + 统一 ERROR n 诊断面板** —— 四家皆无。
5. **安全网完整度**（自动保存 + 恢复快照 + 保存冲突 + 脏文档切换保护）—— 妙言直到 V4.1.0 才修完切换笔记丢稿 bug，这是可对比的信任资产。
6. **三语母语级界面 + Rust 原生工作区索引**（1501 文档 34ms）—— iA 的差异化功能（词性高亮、Style Check）全部不支持 CJK。
7. 多光标（Typora 45👍 未满足）、wikilink（Typora 103👍 未满足）Prism 已有。

## 4. 方法与证据限制

- 竞品侧：WebSearch 不可用，数据来自官方文档/官网 WebFetch + GitHub API + iTunes Lookup API。Typora/妙言的抱怨数据来自 GitHub issue 点赞数（强证据）；**iA Writer 与 Obsidian 的抱怨为文档推断（弱证据）**，Reddit/论坛无法抓取。
- 未核实项：Typora 自动保存/崩溃恢复细节（文档 404）、Typora URL scheme/QuickLook、iA Writer 数学公式支持（无文档，倾向不支持）、妙言应用内全局搜索细节。
- Prism 侧两项待确认（G-10 富文本粘贴、G-12 重命名更新内链）需读码或实测补齐后再定级。
- 本矩阵是差距参照，不是抄袭清单。任何"补齐"决策仍受 CONTEXT.md 写作器定位约束。
