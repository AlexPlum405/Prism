# 采用 Prism 跨平台写作器气质

2026-06-17：Prism 的主视觉和交互判断从“贴近妙言式 macOS Markdown 写作器”收束为“Prism 跨平台写作器气质”。妙言风格仍是重要参考，但不再是唯一标准；Prism 应表达本地优先、内容优先、完整预览、导出可信的跨平台 Markdown 写作器。

## Decision

后续 UI 与交互优化以 Prism 自身的一致产品气质为准：主工作区结构、控件密度、阅读排版、状态反馈、命令组织和诊断体验在 macOS / Windows / Linux 上保持一致；系统窗口 chrome、系统菜单、文件管理器措辞和平台快捷键可以按平台适配。

妙言风格提供克制浅色界面、低对比边框、紧凑工具区、舒适中文长文排版和轻量桌面质感等参考特征，但不能把 macOS 原生拟态、AppKit 细节或“像妙言”作为唯一验收标准。ADR-0005 保留为从 OpenAI 极简方向转向妙言式写作体验的历史背景，本 ADR 作为后续视觉和交互判断的当前口径。

## Consequences

- 设计评审不再只问“是否像妙言”，而是检查是否符合本地优先、内容优先、完整预览、导出可信的跨平台写作器气质。
- 新增状态栏、命令面板、诊断面板、图谱、属性、模板、导出等 UI 时，应优先维护跨平台一致的结构、密度、层级和反馈。
- 视觉系统可以保留妙言式克制、轻量和中文排版优势，但不得把 Prism 变成 macOS-only 产品或某个竞品的外观复刻。
