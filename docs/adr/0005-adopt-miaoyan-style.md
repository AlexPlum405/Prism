# 采用妙言风格作为当前主视觉方向

2026-05-19：Prism 当前 UI 已不再以 `docs/prism-openai-redesign.html` 的 OpenAI 极简原型为主，而是以妙言式 macOS Markdown 写作器体验作为主视觉方向。ADR-0001 保留为历史背景，不再作为新功能 UI 的唯一判断标准。

## Decision

后续 UI 与交互优化以当前 app 的妙言风格为主：内容优先、轻量原生桌面质感、克制浅色界面、低对比边框、紧凑工具区、舒适中文长文排版。

OpenAI 原型中的克制、留白、少装饰等原则可以作为辅助约束，但不继续套用纯黑白双锚点、强 pill 体系或大号 display 排印作为唯一标准。

## Consequences

- 新功能必须先对齐当前 app 的现有妙言风格，不为单个功能引入新的视觉语言。
- 状态栏、命令面板、斜杠菜单、诊断面板、属性面板、图谱等新增 UI 都应保持轻量、低对比、紧凑、桌面应用感。
- `docs/prism-openai-redesign.html` 只作为历史参考保留；如需新的高保真基准，应另建妙言风格参考文档或截图基准。
