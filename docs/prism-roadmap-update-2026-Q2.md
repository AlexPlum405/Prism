## 三、优先级变更

本季度优先级保持 CONTEXT.md 中原有的"低破坏、高收益、打基础"顺序，**无重大优先级变更**。

值得记录的一个自然演进：Rust Core Modernization 原计划作为后续技术方向，但因架构重构和前端模型抽出的推进节奏顺利，在 Q2 内提前完成了 Phase 1 的核心接入（文件 IO、工作区索引、导出任务、设置存储、结构化错误），这为后续 Q3 继续推进 Rust Phase 2 打下了基础。这不属于优先级变更，而是技术路线的自然加速。

## 七、下一步建议

1. **Q3 第一优先：落地 macOS 签名与公证。** 这是当前唯一阻塞产品正式发布的外部依赖。获取 Apple Developer ID 后，签名 → Gatekeeper 验证 → notarization 可在 1-2 天内闭环。同时建立 Windows CI 验证环境。

2. **Q3 第二优先：大文档渲染增量优化。** 性能基线已建立（1 万行含公式 2128ms，KaTeX 占 66%），方向明确：增量渲染（只重渲染变更块）、KaTeX 视口懒渲染、未变更段落 AST 缓存。目标是将大文档单次刷新从 2 秒级降到 200ms 以内。

3. **Q3 第三优先：继续 Rust Core Phase 2。** Phase 1 已完成文件 IO、工作区索引、导出任务、设置存储的 Rust 接入。Phase 2 可以推进搜索、反链/图谱数据层的 Rust 化，进一步提升大工作区下的响应速度。
