# Prism 1.0.0 Launch Copy

## Core Line

把 Markdown 写成漂亮的文稿。

English:

```text
Turn Markdown into polished documents.
```

Japanese:

```text
Markdown を、美しい文書に。
```

## Short Pitch

Prism 是一款开源免费的本地 Markdown 编辑器。它让文档在编辑、预览和导出时保持更完整的版面感，也把主题、三语界面、知识图谱和导出诊断放进同一个桌面写作体验里。

English:

```text
Prism is a free, open-source Markdown editor for local writing. It keeps your files on disk, gives Markdown a refined editor and preview surface, and helps you export documents without losing the page.
```

Japanese:

```text
Prism は、ローカルファイルをそのまま扱える無料・オープンソースの Markdown エディタです。編集、プレビュー、書き出しまで文書としてのまとまりを保ちながら、テーマ、3 言語 UI、ナレッジグラフ、書き出し診断をひとつのデスクトップ体験にまとめています。
```

## Emphasize

- 本地 Markdown 写作
- 编辑、分屏和预览
- 主题系统
- 中文、English、日本語
- 链接、反链和知识图谱
- Mermaid、PlantUML、Markmap、KaTeX
- HTML、PDF、PNG、DOCX 导出
- Finder 文件图标
- 开源免费

## Avoid

- 不说完全替代 Typora 或 MiaoYan。
- 不说 Windows/Linux 已正式发布。
- 不说自动更新已经可用。
- 不说所有导出场景 100% 完美。
- 不说全断网、HiDPI 和长时间内存压力已经完整验证。

## Product Hunt Style

```text
Prism is a free, open-source Markdown editor for local writing.

It is built for people who want Markdown to feel more like a finished document: refined themes, split preview, diagrams, formulas, knowledge graph, and export to HTML, PDF, PNG, and DOCX.

Prism 1.0.0 is available first for macOS Apple Silicon.
```

## GitHub Release Supplement

```text
Prism 1.0.0 is the first public stable release for macOS Apple Silicon.

This release focuses on local Markdown writing, polished preview, theme quality, knowledge graph, three-language UI, and export to HTML/PDF/PNG/DOCX.

Windows and Linux builds will follow after real-device validation. Auto-updater delivery is not included in this release.
```
