## 小红书

```text
做了一个开源免费的 Markdown 编辑器：Prism。

它不是云文档，也不是协作平台。更像一个本地写作器：打开一个 .md 文件，写作、预览、整理链接关系，最后导出成 PDF / HTML / PNG / DOCX。

这次 1.0.0 首发 macOS Apple Silicon。

我最想突出的几个点：
- Markdown 预览更像一篇成稿
- 主题不是简单换色，字体、代码块、表格和引用都会一起变
- 支持中文、English、日本語
- 有链接、反链和知识图谱
- Mermaid / PlantUML / Markmap / KaTeX 都能预览
- 开源免费

下载：
https://github.com/AlexPlum405/Prism/releases/tag/v1.0.0
```
