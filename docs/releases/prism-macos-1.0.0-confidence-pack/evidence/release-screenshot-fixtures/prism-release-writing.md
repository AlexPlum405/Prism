# Prism Release Notes

Prism is a local-first Markdown editor for long-form writing, technical notes, and reliable export.

## A polished writing surface

- Work directly with ordinary Markdown files.
- Keep source and preview side by side when precision matters.
- Use diagnostics to catch broken links, missing images, and export risks before publishing.

> The preview is not a decoration. It is the contract Prism uses for reading and exporting.

## Daily workflow

1. Open a local folder.
2. Write in Markdown.
3. Preview formulas, diagrams, tables, and tasks.
4. Export to HTML, PDF, PNG, or DOCX.

| Need | Prism behavior |
|---|---|
| Long notes | Focused writing and split preview |
| Technical docs | Mermaid, PlantUML, Markmap, KaTeX |
| Local files | No account and no cloud lock-in |
| Release work | Diagnostics before export |
