# 不只写一篇，也整理一组文档

Prism 适合单篇文稿，也适合一组互相引用的本地 Markdown。写作计划、阅读摘录、导出示例和主题说明可以通过链接连成一个小型知识空间。

## 为什么这个镜头重要

图谱镜头不需要解释所有功能。它只需要证明：Prism 不是只打开孤立文件，也能把一组本地文档之间的关系展示出来。

> 拍摄时可打开链接面板、反链面板或知识图谱，让节点关系停留在清晰可读的状态。
