# 同一篇文稿，可以有不同气质

主题不只是换颜色。Prism 的主题会同时影响字体、标题、正文、代码、表格、引用和导出预览。

## MiaoYan

适合长文、读书笔记和中文写作，标题清楚，版面更接近成稿。

## Inkstone

更像纸面编辑：色彩克制，适合慢一点的阅读和整理。

## Slate

适合技术文档和产品说明，边界清楚，结构感更强。

## Mono

适合草稿、实验笔记和代码说明，黑白关系更直接。

## Nocturne Dark

深色主题用于夜间写作，也用于更聚焦的技术预览。

> 拍摄主题视频时，保持这一页不变，只切换主题。让用户看到同一篇文档在不同主题下的整体排版变化。
