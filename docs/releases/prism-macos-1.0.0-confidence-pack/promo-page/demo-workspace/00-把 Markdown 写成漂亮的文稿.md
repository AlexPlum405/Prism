# 把 Markdown 写成漂亮的文稿

> 一篇 Markdown 不必停留在源码里。它可以有清楚的层次、漂亮的预览，也可以在写完之后，以更体面的版面交出去。

Prism 1.0.0 面向本地写作：从 Finder 里的一个 `.md` 文件开始，写笔记、整理资料、制作技术文档，最后导出为 PDF、HTML、PNG 或 DOCX。

## 这组文档用于宣传拍摄

- [[01-主题示例]]：展示不同主题下的文稿气质。
- [[02-图表与公式]]：展示 Mermaid、PlantUML、Markmap 和 KaTeX。
- [[03-知识图谱入口]]：展示链接、反链和知识图谱。
- [[04-导出示例]]：展示写完之后的交付路径。

## 一段真正像文稿的 Markdown

| 场景 | Prism 负责的部分 |
| --- | --- |
| 长文写作 | 标题、段落、引用和列表保持稳定层级 |
| 技术文档 | 代码、公式、图表和表格进入同一个预览节奏 |
| 本地资料整理 | 文件、链接、反链和图谱共同组织上下文 |
| 对外交付 | 预览、导出和诊断形成闭环 |

```ts
type PrismDocument = {
  source: "local";
  format: "markdown";
  output: Array<"html" | "pdf" | "png" | "docx">;
};
```

## 拍摄时的停留画面

这一页适合用于首屏分屏镜头。左侧保留 Markdown 源文，右侧停在标题、引用、表格和代码块都可见的位置，让用户第一眼看见「写作」和「成稿」之间的关系。
