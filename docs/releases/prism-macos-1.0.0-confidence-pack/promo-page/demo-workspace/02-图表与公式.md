# 复杂内容，也要排得体面

技术文档里常常不只有段落。流程、关系、思维导图、公式和代码都应该进入同一个文稿版面。

## Mermaid

```mermaid
flowchart LR
  Draft[本地草稿] --> Preview[预览成稿]
  Preview --> Check[诊断检查]
  Check --> Export[导出交付]
```

## PlantUML

```plantuml
@startuml
left to right direction
actor Writer as W
rectangle Prism {
  usecase "编辑 Markdown" as Edit
  usecase "预览图表公式" as Preview
  usecase "导出文稿" as Export
}
W --> Edit
W --> Preview
W --> Export
@enduml
```

## KaTeX

当一篇文稿需要公式时，排版也不应该突然变得粗糙：

$$
Quality = \frac{Writing \times Preview}{Friction + Noise}
$$
